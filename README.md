# IamHere

В проекте две версии для macOS:

- **Python без установки библиотек:** [python/iamhere.py](python/iamhere.py). Нужен уже установленный Python 3. Подробная инструкция: [python/README.txt](python/README.txt).
- **Приложение в строке меню:** исходники в `Sources/`, сборка командой `bash build.sh`.

## Быстрый запуск Python-версии

Скачайте `python/iamhere.py`, откройте Терминал и запустите файл:

```sh
python3 ~/Downloads/iamhere.py
```

Если скачан весь репозиторий, из его папки выполните `python3 python/iamhere.py`.
Оставьте Терминал открытым. Для остановки нажмите **Ctrl+C**. Не запускайте обе версии одновременно.

Скрипт удерживает экран включённым через встроенную утилиту `caffeinate` и плавно двигает курсор после **13 минут без ввода**. Ввод пользователя откладывает движение, вмешательство во время анимации отменяет её. Чтение и просмотр видео без касаний неотличимы от бездействия.

Проверка доступа к системным API без движения мыши и запуск тестов:

```sh
python3 python/iamhere.py --check
python3 -m unittest discover -s python -v
```

## Приложение для macOS

Небольшое приложение для macOS: после 13 минут бездействия плавно двигает курсор в несколько случайных сторон и возвращает его на место. Поддерживает несколько мониторов. Движение мыши, клики, прокрутка и клавиатура откладывают автоматическое движение ещё на 13 минут. Если пользователь вмешивается во время анимации, она прекращается без возврата курсора.

Пока таймер включён, системная утилита `caffeinate -d` удерживает дисплей от автоматического сна, в том числе во время работы пользователя. Пауза и выход снимают это удержание.

## Запуск

Откройте `build/IamHere.app` двойным щелчком в Finder. В строке меню появится значок мыши. Первое движение произойдёт через 13 минут.

Нажмите значок, чтобы увидеть обратный отсчёт, приостановить таймер, проверить движение кнопкой «Двинуть мышь сейчас» или выйти. Проверка не сбрасывает основной таймер. После продолжения и после пробуждения Mac отсчёт начинается заново.

Приложение не запускается автоматически при входе. Во время принудительного сна Mac таймер не работает. Приложение не отменяет блокировку экрана и не гарантирует изменение статуса в других программах.

## Сборка

Нужен Swift из Xcode или Command Line Tools. В папке проекта выполните:

```sh
bash build.sh
```

Сборка создаёт универсальное `build/IamHere.app` для Intel и Apple Silicon с macOS 12 или новее и подписывает приложение локальной ad-hoc подписью. Внешних зависимостей нет.

## Перенос на другой Mac

Передайте `build/IamHere.zip` на другой Mac, распакуйте и переместите `IamHere.app` в папку «Программы». Откройте приложение: в строке меню появится значок мыши. Устанавливать Swift или Xcode на втором Mac не нужно.

Сборка не нотарифицирована Apple. Если macOS блокирует её запуск, после первой попытки откройте «Системные настройки» → «Конфиденциальность и безопасность» и разрешите запуск этого приложения. Названия разделов могут отличаться в разных версиях macOS.

Для Windows или Linux нужна отдельная версия приложения.
