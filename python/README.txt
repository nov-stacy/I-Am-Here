IamHere — отдельная версия на Python для macOS

Нужен уже установленный Python 3. Дополнительные библиотеки, pip,
Xcode, установка приложения и sudo не нужны. Старое приложение сохранено.

1. Перенесите файл iamhere.py на другой Mac, например в «Загрузки».
2. Откройте «Терминал» и выполните:

   python3 ~/Downloads/iamhere.py

3. Оставьте Терминал открытым. Остановка: Ctrl+C.

Если файл лежит в другой папке: введите python3 и пробел, перетащите
iamhere.py из Finder в Терминал и нажмите Enter.

Скрипт постоянно удерживает дисплей от автоматического сна с помощью
встроенной caffeinate. После 13 минут без ввода он плавно двигает курсор
в случайные стороны и возвращает на место. Любой ввод откладывает движение;
при вмешательстве во время анимации она отменяется без возврата курсора.
Удерживаемые клавиши и кнопки мыши тоже считаются активностью.
Первое движение — не раньше 13 минут после запуска; после пробуждения
отсчёт начинается заново. Ничего не нажимается и не печатается.

Активность определяется по вводу. Чтение и просмотр видео без касаний
неотличимы от бездействия. Скрипт не отменяет принудительный сон,
закрытие крышки, блокировку экрана или ограничения администратора.
Ctrl+C или закрытие Терминала прекращают удержание экрана.
Не запускайте одновременно со старым приложением: у него свой таймер.

Проверка системных API без движения мыши:
   python3 ~/Downloads/iamhere.py --check

Если macOS или политика компьютера запрещают управление курсором,
скрипт сообщит об ошибке; обходить ограничения он не пытается.
